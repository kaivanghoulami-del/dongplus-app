## 🔒 حریم خصوصی و امنیت اطلاعات

برخلاف بسیاری از اپلیکیشن‌های مالی، [دونگ پلاس](https://dongplus.ir/#privacy) بر بستر معماری **Local-First** ساخته شده است:
1. هیچ سروری برای ذخیره یا تحلیل داده‌های کاربران وجود ندارد.
2. سیستم‌عامل اندروید به دلیل عدم تعریف مجوز شبکه، امکان ارسال داده به بیرون را مسدود می‌کند.
3. امکان تهیه نسخه پشتیبان رمزگذاری‌شده با گذرواژهٔ شخصی (Encrypted Backup) توسط خود کاربر فراهم است.
